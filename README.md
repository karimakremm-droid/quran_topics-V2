# QuranApp — نسخة GitHub Pages

## طريقة النشر
1. أنشئ مستودعاً جديداً على GitHub (مثال: `quran`).
2. ارفع **محتويات** هذا المجلد إلى جذر المستودع (وليس المجلد نفسه).
3. Settings → Pages → Source: `Deploy from a branch` → Branch: `main` / `(root)` → Save.
4. افتح الرابط: `https://<username>.github.io/<repo>/`

كل المسارات نسبية، لذا يعمل الموقع في أي مجلد فرعي.

## ملاحظات
- التحميل الأول يجلب ~500KB فقط (واجهة التطبيق)، أما البيانات الكبيرة (الأحاديث، التفاسير، الصور) فتُحمّل عند فتح القسم المعني وتُخزَّن تلقائياً للعمل دون إنترنت.
- `sw.js` هو عامل الخدمة (العمل دون اتصال). رقم الإصدار الآن 98 (مطابق لنسخة أندرويد 9.7)؛ عند نشر تحديث لاحق غيّر رقم الإصدار في `sw.js` ورابط `app.enc` وبصمة SHA-256 في `index.html`.
- لا تحذف ملف `.nojekyll` وإلا تجاهل GitHub بعض الملفات.

## تحديث المتصفح والخصوصية
- يُجلب `app.enc` الجديد عبر رابط مرقّم ويُتحقق من بصمته قبل تشغيله؛ تُزال مخازن النسخ القديمة آلياً بعد التحديث مع الإبقاء على اللغة والمفضلة وتقدم القراءة. يلزم اتصال بالإنترنت لاستلام التحديث أول مرة.
- قواعد `_headers` تطبّقها منصات تدعم هذا الملف (مثل Netlify/Cloudflare Pages)، **ولا تطبقها GitHub Pages**. فعّل HTTPS وترويسات الحماية عبر الاستضافة أو CDN عند الحاجة.
- تشفير ملفات JavaScript وبيانات التطبيق بمفتاح مُضمّن في المتصفح لا يوفر سرية حقيقية؛ لا تضع كلمات مرور أو مفاتيح خاصة أو بيانات مستخدمين حساسة في هذه الحزمة الثابتة.
